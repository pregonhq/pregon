# ADR-0011: Naming and distribution
Status: Accepted

## Decision
Name: Pregón (`pregon` in code). GitHub organization `pregonhq` (fallback `pregonlabs`).
Free GitHub-based identifiers: repo `github.com/pregonhq/pregon`, docs on GitHub Pages,
Maven groupId `io.github.pregonhq` (permanent once published), npm scope `@pregonhq`,
images `ghcr.io/pregonhq/*`. A custom domain may be added later only for the website,
not for the groupId.
